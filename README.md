# Stella AI - Public Resources

This repository contains public resources and testing documentation for Stella AI, an intelligent assistant for biological and biomedical research.

## 📁 Directory Structure

### `logo/`
Contains the official Stella AI logo and branding assets.

### `testing/`
Testing resources and documentation for quality assurance:
- **TEST_QUESTIONS.md** - Comprehensive test cases covering different difficulty levels and features
- **TEST_RESULTS_TEMPLATE.md** - Template for documenting test results
- **test-data/** - Sample data files for testing
- **test-results/** - Archived test execution results

## 🧪 Testing

The testing directory provides structured test cases organized by difficulty levels, ranging from easy to hard. Use these test cases to validate functionality across different releases and configurations.
